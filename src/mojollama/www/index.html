Features

⚡ MoE-Optimized

C-accelerated fused MoE forward kernel with expert dispatch — up to 2.3× faster than llama.cpp on GPT-OSS and Qwen3 MoE models.

🏗️ Multi-Architecture

Llama, Mistral, Qwen2/3, GPT-OSS, Gemma 4, ZAYA1, DeepSeek V2/V3, DBRX, Mixtral, Falcon, Phi, and 50+ more architectures.

🔋 GGUF Native

All quantization types: Q4_0, Q4_K, Q5_K, Q6_K, Q8_0, MXFP4. Full K-quant support including Q5_K and MXFP4 experts.

🧬 Hybrid SSM+Attention

Qwen3.6-35B support with Mamba-2 SSM + Attention hybrid layers, MXFP4 quant, and concurrent serving at 47 tok/s.

🧩 Gemma 4 & ZAYA1

Gemma 4: per-layer projections, GeGLU activation, sliding window attention, logit softcapping. ZAYA1: interleaved ATTN/MoE+MoD, CCA, SSM conv1d.

📦 Docker Ready

Pre-built image on GHCR with auto-tune on first load, HuggingFace model download, and docker-compose for all services.

🔧 Hardware Auto-Tune

Sweeps OMP threads, batch sizes, concurrency levels, and MojoLlama engine settings. Finds optimal config for your CPU.

🖥️ Studio Web UI

Built-in web interface for chat, training, dataset management, model export, and evaluation — all from your browser.

🔄 Unified CLI

Single `mojollama` command for chat, serve, bench, quantize, convert, autotune, eval, train, export, and hub operations.

Quick Start

Install

# Clone and install
$ git clone https://github.com/a730/MojoLlama.git
$ cd MojoLlama/src && pip install -e .

# Or use Docker
$ docker pull ghcr.io/a730/mojollama:latest

Basic Usage

$ mojollama chat -m model.gguf
$ mojollama serve -m model.gguf -p 8080
$ mojollama bench -m model.gguf -n 256
$ mojollama quantize model.gguf -t Q4_K_M
$ mojollama autotune -m model.gguf --mojollama

Docker Compose

# Start API server with auto-download
$ HF_REPO=bartowski/TinyLlama-1.1B-GGUF \
HF_FILE=tinyllama-1.1b.Q4_K_M.gguf \
docker compose up -d
