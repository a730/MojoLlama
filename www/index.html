Inference at the speed of Mojo

MojoLlama is a high-performance LLM inference engine combining GGUF support, continuous batching, and PagedAttention. Built in Mojo/MAX to exceed llama.cpp speed while being simpler to deploy.

Why MojoLlama?

⚡

Multi-Backend

Auto-selects the fastest backend — llama.cpp (85 tok/s CPU), MAX GPU, or Mojo SIMD. No configuration needed.

AutoBackend

Streaming Chat

Real-time token-by-token streaming via SSE. OpenAI-compatible API so it works with any client.

Streaming

LoRA Fine-Tuning

HF → GGUF Export

Convert any HuggingFace model to GGUF with one command. Supports all quantization types (Q4_0 through Q8_0).
