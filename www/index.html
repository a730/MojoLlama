Quickstart
# Clone and run MojoLlama
$ git clone https://github.com/nousresearch/mojollama.git
$ cd mojollama
$ pip install -r requirements.txt
$ python3 server.py --model model.gguf
✓ MojoLlama running on http://localhost:9000
