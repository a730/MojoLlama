Features

Built for local LLM workloads

From single-token inference to production concurrent serving — MojoLlama scales to your hardware.

⚡

MoE-optimized engine

C-accelerated fused MoE forward kernel with expert dispatch. Up to 2.3× faster than llama.cpp on GPT-OSS and Qwen3 MoE models.

2.3× vs llama.cpp
🧬

Hybrid SSM + Attention

Qwen3.6-35B with Mamba-2 SSM + Attention hybrid layers, MXFP4 quantization, and concurrent serving at 47 tok/s aggregate.

🧩

Gemma 4 & ZAYA1

Gemma 4: per-layer projections, GeGLU activation, sliding window, logit softcapping. ZAYA1: interleaved ATTN/MoE+MoD with CCA.

🔌

50+ architectures

Llama, Mistral, Qwen, GPT-OSS, DeepSeek V2/V3, DBRX, Mixtral, Gemma 4, ZAYA1, Falcon, Phi — pluggable forward passes for any GGUF model.

🔋

GGUF native

All quantization types: Q4_0, Q4_K, Q5_K, Q6_K, Q8_0, MXFP4. Full K-quant support including Q5_K and MXFP4 for expert weights.

🔄

Concurrent serving

Multi-process server with configurable workers. Up to 47 tok/s aggregate on Qwen3.6-35B with 10 concurrent users.

🔧

Hardware auto-tune

Sweeps OMP threads, batch sizes, concurrency levels, and engine settings. Caches per-model optimized config on first load.

📦

Docker ready

Pre-built image on GHCR with auto-tune, HuggingFace model download, and docker-compose for API server, chat, and llama.cpp fallback.

🖥️

Unified CLI

Single mojollama command for chat, serve, bench, quantize, convert, autotune, eval, train, export, and hub operations.

Getting started

From zero to inference

Install MojoLlama and run your first model in minutes.

Step 01

Install

Clone the repository and install dependencies.

$ git clone https://github.com/a730/MojoLlama.git
$ cd MojoLlama/src && pip install -e .
Step 02

Download a model

Get a GGUF model from HuggingFace or use your own.

$ mojollama convert --hf meta-llama/Llama-3.2-1B \
--outtype q4_0
Step 03

Run inference

Chat, serve, or benchmark — all from one command.

$ mojollama chat -m model.gguf
$ mojollama serve -m model.gguf -p 8080
